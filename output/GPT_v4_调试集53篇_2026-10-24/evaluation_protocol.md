# 本轮 GPT 调试集提取与评分口径

用户要求在当前对话用 GPT 提取 53 篇，并明确允许 GPT 子代理并行提取和交叉核对。不调用外部付费 API。现行方案仍为项目方案 §5.7 v4。此任务不是独立测试集的正式准确率验收。

## 数据隔离

- 提取阶段只读方案及 `sources/{ID}.json` 的全文和 SI；不读取既有科学提取结果。
- `independent_predictions/{ID}.json` 是首次独立预测，完成一篇即保存。根代理记录 SHA256 后禁止覆盖；改正另存 `revisions/`。
- 之前的 `v4_records/` 是参考迁移初版，不是本轮独立预测，不能用其与旧结果自比。
- 一组代理提取、另一组代理交叉复核。复核可读取独立预测、旧 Claude 参考、原文和机械检查。AI 复核不填任何人工 gold 或人工核对格。

## 计数单位及口径

分别报告：一个测试及其条件、一个比较内一个指标的方向、一条机制说法。重复陈述只计一个语义单位。测试拆分与合并要按原文条件核对，不能只比较编号。机制核对内容、来源、过程类别与落到的测试，不以关键词相同判对。

- TP：预测单位经另一代理按原文核对为正确；旧参考没有但原文支持的新正确项也可计 TP，标为新增正确。
- FP：预测单位经原文核对为错误、夸大、归属错误或无法得到支持。不能因为旧参考没有就直接算 FP。
- FN：原文中应提但独立预测未提的单位，由旧参考和补充原文复核发现，逐项记录证据。原参考错误不能算 FN。
- 未决：证据缺失、数值只在未核验图片等，明确标记，不默认为正确；单列数量和覆盖率，不偷偷从分母消失。
- 精确率 = TP / (TP + FP)，召回率 = TP / (TP + FN)。只在复核完成的明确范围内计算；分母为零记不可计算。
- 本轮参考由 AI 辅助核对，并非完整人工 gold。最终结果须称“调试集、AI 核对参考下的暂定指标”，不能据此声称达到独立测试验收线。参考未覆盖内容的真实漏提可能仍存在。

## 机械校验和图片

代码检查引用编号、数字出处、关联和方向。原句能定位仅代表证据可追溯，不等于含义正确。仅正文数字与作者定性分别保存；条件不同、跨图未证明同批或说法不一致依规则不判。

只读循环容量侧及梯度缺数图。模型给轴和曲线语义、代码给几何读数，遵循 §5.7 的标定与同测试数字锚点规则。读图失败或无锚点单列“仅图未读”；不目测造数字。首版预测与后续图片补充分别保存，并分别说明评分时使用的是哪一版本。

## 已知范围限制

53 篇正文缓存均有；S53、P212、P296、P432 无本地 SI。P014/P039 后判不合格但保留调试。机制留出 S34/S35/S38/S52/S55/S56 不读取。53 篇均参与过方案开发，不能称未见数据；当前对话没有固定 API 模型快照，不能直接代替未来正式 API 评估。
