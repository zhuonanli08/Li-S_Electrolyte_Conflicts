# 第一部分：方案原文（§0 主线、§5.7 论断式提取）

## 0. 主线

> **强、弱溶剂化电解液常见"强者首圈容量和动力学占优、弱者循环稳定占优"的权衡。两侧各自受什么过程限制？据此能否设计出在实用条件下兼顾两者的电解液？**

（2026-10-19 用户定；取代方案 3 的"初始优势能否持续、早期诊断能否预测"。）

| 问题 | 内容 | 怎么回答 |
|---|---|---|
| **Q1 权衡的分布** | 权衡有多普遍、在什么条件下出现、哪些研究打破了它（一侧全面占优） | 论断式提取（§5.7 v4）：同一篇、同一测试（条件全部相同、写具体数值）内判各指标变好/变坏/未报告，梯度论文写沿梯度的趋势和最优档；一篇一条结论；性能数值只用来判方向；深入证据集的优势一致性（§6.6）为历史材料 |
| **Q2 两侧的限制机制** | 强溶剂化一侧的寿命被什么耗掉（K1 活性锂 / 硫库存损失，还是 K3 电解液 / LiNO₃ 耗竭）；弱溶剂化一侧的容量 / 动力学不足是不是可逆的传输 / 转化限制（K2），能否补回；"全面占优"是真兼顾还是对照偏弱 | 每篇的机制说法挂整句原文、标来源和过程大类（§5.7）→ 全部提完后跨文献在共同尺子上对照：共识 / 矛盾 / 常说没测（§8.3a）；机制判别表 + Ⅱ 类 26 篇（§6.7）作补充 → 实验诊断（§10） |
| **Q3 兼顾设计** | 按 Q2 的结论先写预测：在贫液、薄锂等实用条件下，哪种兼顾策略（折中 = 适中溶剂化；解耦 = 降低 Li⁺ 侧溶剂化、在多硫化物侧补偿）能同时保住容量和寿命；再设计配方验证 | 实验，最后一步（§10）：先在文献已有体系里调出适中配方（形式 A），与强、弱两端同条件比较并测两侧诊断量；留出论文和预留配方检验预测（§11） |

- **出发点**：锂硫电解液文献在"多硫化物该不该溶解""强 / 弱溶剂化哪个好"上结论打架，常见的情形是两侧各赢一部分指标。
- **新意不在"解释权衡为什么存在"**："溶解多 → 反应快、但穿梭重"在领域里已是共识。新意在：定量识别两侧各自的限制过程；检验"打破权衡"的配方是真兼顾还是对照偏弱；用机制先写预测，再设计配方。
- **不预设权衡必然存在**：深入证据集里两侧都有全面占优的论文（§16.3），它们是"能兼顾"的线索，也可能来自对照偏弱。
- **设计的定位是检验机制**：配方好坏都有结论——预测与诊断均符合时，机制解释获得支持；预测失败时检查解释及其适用条件。单次预测命中不等于唯一证实机制。适中溶剂化、Li⁺ / 多硫化物解耦已有人做（§2.2），不以"再做一个性能更好的电解液"为唯一目标。
- **不做寿命预测模型**（10-19 用户定）：用早期循环数据预测寿命属于电池寿命预测 / 健康状态评估方向，需要上百颗电池，也会把重心从电解液化学拉走。保留两样：诊断节点作找机制的手段；留出论文和预留配方检验"机制规则能否预先说对"，不预测寿命数值。
- **E/S 与锂库存**：检验机制的实验条件（权衡可能随条件变化），不是要被"找出来"的解释本身。
- **实验放在最后一步**（10-19 用户定）：文献线做完再定实验细节；文献里用到的表征和定量方法，实验室都有条件和资源做，原定的"定量方法决策关口"不再是卡点（§9）。
- **文献部分**：全库系统筛选 + 合格论文**论断式提取**（§5.7，10-22 与师兄讨论定，10-24 定为 v4）。不同论文装电池的方法不同，**不做跨论文数值比较**；只在同一篇同一条件内比较 A/B 的方向（篇内定方向），并提取作者的机制解释（整句原文 + 来源，过程按四个大类多标，不设证据等级）；跨文献只在共同尺子的同一段上比机制（篇间比机制，§8.3a），归纳出共识、互相冲突、被普遍相信但没人直接测过的解释，作为实验对象。原则是降低每篇的提取深度，而不是过早缩小覆盖范围。
- **数值的用途**（10-24 用户定）：性能数值不作分析对象，不为跨论文比大小而收集。只留三类数：测试条件（本身就是统一标准，E/S 5 在哪篇都一样）、配方用量（算尺子）、判方向用的那一对数（防止只听作者说好——四篇表样里三篇的作者最优配方在某一项上比对照差：S11 首圈容量、S33 0.5 Ah 软包首圈能量密度（读图才看到）、S39 GITT 测试的首次放电容量和过电位（作者定性；S39 长循环首圈容量因作者说法前后不一按规则不判））。横向“谁提高得多”文献答不准，留给最后自己的实验在同一条件下比（§10）；但“提高”多大取决于对照多弱（S21：对照不加 LiNO₃ 时 200 圈保持率 90.6% vs 12.2%，对照也加 LiNO₃ 后 600 圈损失 29.9% vs 50.7%），所以结论里写清对照类型，跨文献时同类对照放在一起看。
- 数据支持到哪一步，结论就推进到哪一步。

**可能的结果**（草稿）

|---|---|
| Q2的机制解释得到诊断支持，Q3预测符合 | 在被检验条件下支持该机制规则，给出兼顾设计的依据及适用条件 |

### 5.7 论断式提取（2026-10-22 用户与师兄讨论定；10-23 修订；10-24 定为 v4，现行提取格式）

```
合格论文（B 步资格筛选结果可直接用）
        ↓
每篇一个 JSON：配方（组分逐个记）→ 梯度（每档都记）→ 性质 → 测试（条件全部相同的一组实验，写具体数值）
  → 每个测试下的结果 → 机制（作者说法：一句原文一条，标来源和这句提到的过程大类）
        ↓
程序：原句查原文 → 只在同一测试内判好坏 → 算尺子（🧮）→ 拼一篇一条结论 → 生成复核用 Excel（7 页）
        ↓
全部论文提完后：跨文献比较（§8.3a）——共识 / 矛盾 / 常说没测
        ↓
挑出相互冲突、或被普遍相信但没人直接测过的解释 → §10 实验
```

**为什么改。** 师兄意见（用户采纳）：同时逐值提取配方、电池性能、测试条件工作量太大；不同工作装电池的手法不同，跨论文的性能数值本身不可比。电池结果不同，但所依据的机制、解决的问题和结论有共性，应从文献的论证逻辑中提取结论，再据此设计实验。补充约束：作者的机制解释常是事后说法，所以每条解释挂整句原文并标来源（本文结论 / 推测 / 转述他文），不用截出来的词；10-24 用户定不再另设证据等级——看原句就知道有没有证据。

**10-24 定稿（v4，用户定）。** 在 v3（10-23 晚，机制链 + 跨文献三页的演示稿）基础上精简：
- **篇内定方向、篇间比机制**：性能数值只用来判“变好 / 变坏”，不进分析、不跨论文比大小（§0“数值的用途”）。
- **一篇一条结论**，固定四行（见下）。
- **机制一句一行**：整句原文 + 来源 + 这句提到的过程大类；过程只分四个大类、可多标（穿梭常和负极锂腐蚀一起讲，S11、S21、S39 原句都是如此，硬分一类反而不准）；删去 v3 的节点、箭头和“直接 / 间接 / 只是说法”证据等级。
- **跨文献比较要同一标准**：各篇自己的档位（S11 的 10% HFE、S21 的 60% DTL）不可比；用“每个 Li⁺ 分到的配位溶剂分子数”作简单尺子（配方 + 手册，不用 DFT/MD）。v3 的跨文献三页移到全部论文提完以后（§8.3a）。
- **不收**：介电常数、各篇自算的结合能（方法各异、跨篇不可比）、效应量、跨测试合并的“总体”。

**10-23 修订的原因**（用户提出）：一篇论文常有多种测试条件，可能一个条件下首圈容量升高、另一个条件下衰减变慢。10-22 版没有定义“一组条件”，S21 表样把 0.1 C 首圈容量和 1 C 200 圈保持率并成一条、程序判“总体变好”——这会把权衡误判成兼顾。另外每篇只记作者最优配方对对照，梯度中间有没有最优点看不出来；成分是一整段文字，程序算不出描述符；条件里“薄锂”“贫液”这类概括丢了数值。

**一篇一个 JSON。** 一个**测试** = 条件全部相同的一组实验；每个结果只挂在它所在的测试下，好坏只在同一测试内判，不把不同测试的指标拼在一起。

| 部分 | 记什么 | 规则 |
|---|---|---|
| 配方 | 每个配方一行：代号、作者原名；**组分逐个记**：名称、角色（溶剂化溶剂／弱或非溶剂化溶剂／盐／添加剂）、原文用量、原文单位 | 沿用 S/P 编号；角色按作者的描述定；用量和单位照抄原文（M、m、wt%、摩尔比、v/v） |
| 梯度 | 梯度变量、各档顺序和取值、排序依据（按溶剂化由强到弱排） | **每一档都记**，不只记作者最优对对照；分清用量梯度（同一溶剂加 0/10/20/30%）和种类梯度（换溶剂、用量不变，如 S33、S39） |
| 性质 | **Li⁺ 溶剂化**、**多硫化物溶剂化**、**多硫化物溶解度**分开记；离子电导率、黏度、离子迁移数；原文另测的（如 Li⁺ 扩散系数）也记 | 有数值记数值，只有排序记排序，只有相对对照的方向记方向；附测法和测量体系（在简化溶液里测的写明差别）；没测写“未报告”。只记高低，不判好坏 |
| 测试 | 电池（电极组合＋形式）、硫载量、E/S（注明体积基或质量基）、锂厚、倍率（含化成协议、1C 定义）、温度、LiNO₃；参与的配方 | **条件一律写具体数值，不用“薄锂”“贫液”等概括**；有一项不同就拆成两个测试，化成圈不算不同条件。没写的记“未报告”，不填默认值。A、B 条件分别给值且不同（如 E/S 3.7 vs 3.3）时标“条件不同，不判” |
| 结果 | 每个测试下逐项记：首圈容量、寿命或保持率（注明口径）、库仑效率、倍率容量、过电位；自放电、阻抗、穿梭电流等有就记；每项写取值点 | **只为判方向而记**：正文写了数字记数字（≈、>、< 原样保留）；只有作者文字记“作者定性”；文字里没有的按下文“读图”规则只读两类图 |
| 机制 | 作者的一条说法：比较的两个配方（作者说的是整条梯度时注明“全梯度”）、性质变化（写明是哪种溶剂化）、过程大类及怎么变、落到哪个测试哪项表现、AI 写的中文概括；每条至少挂一句整句原文 | 每句标**来源**（本文结论／本文结论（与他文一致）／本文推测／转述他文或通用说法）和**这句提到的过程大类**（正极反应／多硫化物穿梭／负极锂／电解液消耗）：原句提到哪类就标哪类，可多标，不靠推断。作者的说法覆盖整条梯度时记全梯度，不只截一段。只靠转述句支撑的说法不算本篇结论。作者在同一篇里自己写了例外的（如 S33 的 ETFE），把那句也挂上 |
| 设计主张 | 折中／解耦、最优配方、原句 | 同上 |
| 出处 | 每项附原句和位置 | 代码到全文缓存逐句核对 |

**程序做的（🧮 及核对）。**
- 成分：只做不需要额外假设的换算——体积份或 vol% → 溶剂体积分数；摩尔比 → 溶剂摩尔分数、盐 : 溶剂化溶剂摩尔比。mol/L 换摩尔比需溶液密度，不算；原文小写 m（mol/kg 还是 Wiley 排版的 mol/L 不明）按规则不换算。v4 不再逐组分做“改变了什么”的差（v3 那一步把不同比例基数的体积份直接比，如 DOL/DME 1:1 → DOL/F4DEE 4:1 写成“DOL 1 → 4 体积份”，实际是 50% → 80%）。
- 方向：按 §7.11，|A − B| ÷ max(A, B) < 5% 记差异小；库仑效率不设阈值，写百分点差；≈、>、< 按区间比，区间重叠记无法判断。梯度趋势按相邻两档比（逐级变好／随梯度变好／先变好后变坏／有起伏／各档差异小），写最优档，缺档写“未报告”。
- 哪一侧的短板：说法里溶剂化较强的配方变坏 → 强溶剂化一侧的短板；较弱的变坏 → 弱溶剂化一侧的短板；起点不是溶剂化（如电导率、溶剂本身腐蚀锂）或没落到电池表现的，归“其他说法”。
- 篇内核对：机制说法落到的表现，到本篇同一测试的数据里核对作者说的变好/变坏。
- 原句与数字核对：每句原句必须在全文里；每个数字必须出现在它挂的原句里（英文数字词也认，如 eight cycles）；测试条件的数也可以出现在本篇其他测试的条件原句里（几个测试共用一套电池）；反算、推算的数写明公式。原句放回原文查引文编号、转述说法、推测词，与 AI 判的来源对不上的、“这句提到的过程大类”与句中关键词对不上的，记进程序核对记录，留到分析阶段（§8.3a）再看。
- N/P：按 §7.4 算设计值与实测值（实测用同一测试里对照的实测首圈容量）。

**原文没写清的，按固定规则处理，不交人判（10-24 用户同意）。**

| 情况 | 规则 |
|---|---|
| 原文没写（如 S11 软包 medium 对应哪一档、S21 DME:THF 比例只在图片表里） | 记“原文未写”，结论里照原文写 |
| A、B 条件分别给值且不同（如 S21 极贫液 E/S 3.7 vs 3.3） | 不算同一测试，不判 |
| A、B 的数来自不同图，原文没说是同一批电池（如 S21 第 400 圈 640 vs 230） | 不判 |
| 作者说法前后不一（如 S39 F4DEE 首圈容量） | 不判；有锚点的图可读时改用读图 |
| 单位含义不明（如 S33 小写 m） | 不换算，尺子不算 |
| 从“长 25%”“超过 6 倍”这类说法反算的数 | 写明公式照用 |
| 读图没有锚点或锚点核不上 | 整张图不用，记“仅图未读” |
| 条件是推定的（如“按 Fig. 3 同组电池推定”） | 照记并写“推定” |

**尺子：每个主盐 Li⁺ 分到的配位溶剂分子数（10-24 用户定：不用 DFT/MD，只用配方 + 手册）。**
- 定义：配位溶剂的物质的量 ÷ 主盐的物质的量。摩尔比：精确；mol/L：按“溶剂体积 ≈ 溶液体积”粗算；小写 m 不换算。分子量、密度、配位能力（配位／不配位／不明，附依据）记在溶剂表；DME、DOL、THF 的密度已按 Sigma-Aldrich 产品页核对（25 °C）。
- 稀释剂不进溶剂化层，但会减少每个 Li⁺ 分到的溶剂：“盐固定、稀释剂顶替一部分溶剂”时尺子变小（S11 12.0 → 8.4），这正是稀释剂起作用的方式；“往配好的电解液里再加稀释剂”时比值不变（整体稀释被比值消掉）。整体稀释对多硫化物溶解度有影响（每升里配位溶剂越少溶得越少），所以**尺子只代表 Li⁺ 一侧**，多硫化物一侧看实测溶解度。
- LiNO₃ 不计入：按摩尔数它不小（S11 2 wt% ≈ 0.32 M，约为主盐的三分之一），但 wt% 换摩尔数要假设溶液密度，NO₃⁻ 是否进溶剂化层各体系不同（S33 的 MD 显示进入，其他论文多数没说）；LiNO₃ 本来就是 7 项测试条件之一，跨文献对照时单独比（§8.3a）。
- 同时给“电解液类别”：常规／加稀释剂／高浓度（主盐 ≥ 3 M 或 3 m）／含配位能力不明的溶剂，并写出配位溶剂是哪几种。
- 可比范围：同类、配位溶剂相同 → 直接比；稀释剂不同 → 粗比（稀释剂按不配位）；主溶剂不同 → 粗比（DN 从同一本手册取）；含配位能力不明的新溶剂（如 S33 的四种氟化醚、S39 的 F4DEE）→ 放不上尺子，只在篇内比。
- 表样里看到的局限：S39 把 DOL/DME 换成 DOL/TTE，尺子上 12.0 → 11.4 几乎不变，而 Li₂S₆ 溶解度 1.0 → 0.22 M、Li⁺ 溶剂化也明显变弱——尺子不区分 DOL 和 DME 的配位强弱，所以“配位溶剂不同”只能粗比，不能当成同一刻度。实验先做形式 A（§10）时不需要 DFT/MD；以后若要设计文献里没有的新溶剂（形式 B），再算描述符。

# 第三部分：工作流程与隔离（每个子代理必须遵守）

**只许读**：本文件 `extraction_spec.md`、`sources_txt/{ID}.txt`（必要时 `sources/{ID}.json`，内容相同）。
**禁止读**：本项目里任何其他提取结果或参考，包括但不限于 `output/` 下除本文件夹以外的所有文件夹（如 GPT_v4…、第一阶段_证据表、论断式提取表样…、第二阶段_C步试提、text_cache）、`进度.md`、课题方案全文、`不适用/`、本文件夹下的 `independent_predictions/` 中别的论文、其他代理的草稿。也不上网查。所需规则都已抄在本文件第一部分。

**每篇的步骤**：
1. 通读 `sources_txt/{ID}.txt` 全文（正文 + SI，分段读完，不跳读、不只靠关键词搜索；参考文献列表可略读）。原句编号就是每行开头方括号里的 `M0001`/`S0001`。
2. 按第一部分的规则和第二部分的格式写 JSON 草稿到 `drafts/{ID}.json`（UTF-8）。
3. 运行格式检查：`python scripts/step9a_claude_debug53.py check "output/Claude_v4_调试集53篇_2026-10-25/drafts/{ID}.json"`（在项目根目录 `D:\Desktop\课题二锂硫电解液矛盾归因` 下运行）。只检查格式（JSON、字段、取值范围、原句编号存在、编号引用），不检查内容对错。有问题改草稿再查。
4. 格式通过后冻结：同一命令把 `check` 换成 `freeze`。冻结后的 `independent_predictions/{ID}.json` 不能再改；冻结后发现自己提错，不要改，也不要另存，在最终汇报里写一句即可。
5. 一篇冻结后再做下一篇。

**提取要求重申**：
- 每个数字必须出现在它挂的原句里（测试条件的数可以在本篇其他条件原句里）；反算的数在 reason 里写公式。
- 机制一句一条，标来源和过程大类；作者说法覆盖整条梯度时记“全梯度”；只靠转述句支撑的说法照记但 source_type 标“转述他文或通用说法”。作者在同一篇里自己写的例外也挂上。
- 只读两类图：Li‖S 循环类测试里文字缺的同一测试容量侧；梯度上只在图里有数的档。阻抗谱、XPS、SEM、电压曲线等不登记。
- 不确定的照原文写并在 reason 或 gaps 说明，不编造、不用常识补数。
