### 7.17 统一 DFT/MD 描述符与自动化计算 agent（10-29 拟议路线）

**用途与精度目标。** 计算服务于区分电解液的分子相互作用、溶剂化与传输特征，不以引入软件或 agent 本身作为创新点，不要求高精度复现全部实验物性。优先保证定义、方法与输出的一致性，并抽样检验相对顺序是否稳定；“同方法”不等于误差自动抵消，不能只要求各配方算出不同数字。

**数据策略建议：统一自算为主，公开数据用于参考和校验。**

1. 主分析的计算特征来自版本化统一协议；组分对和实际配方去重后计算，不按论文重复算。同一组分在不同论文中的实测值仍按来源保存。
2. 公共资源优先提供结构、候选构型、力场/流程参考及基准值；不同方法、不同化学物种或不同组成的数值不直接填入统一特征列。协议与对象相符且可追溯的数据可以评估后复用，不能仅因指标同名就混合。
3. 文献实验性质、文献模拟性质、外部数据库性质、本课题 DFT/MD 值分别保存；保留覆盖缺口和失败原因，不以补齐为由伪造结果。公开资源不全不再决定本课题的计算覆盖。
4. 成本优先用于文献实际出现的组分/配方及科学问题涉及的组合，不全空间穷举。先小批验证，再按预算扩展；本次不提交计算任务。

**两条计算流水线。**

| 流水线 | 计算对象/输出 | 统一内容与复用边界 |
|---|---|---|
| DFT：组分与团簇 | 溶剂—溶剂、溶剂—Li⁺、溶剂—盐阴离子/离子对、溶剂—明确多硫化物的结合能；可附电荷、偶极矩 | 固定物种、电荷/自旋、计量、构型搜索、泛函/基组、色散、环境和能量定义；实际采用的子集后续确定。同一组分对＋同协议可缓存，不随论文重复 |
| MD：具体配方 | 指定组成、浓度、温度和多硫化物状态下的配位、离子对/聚集、扩散；进一步计算黏度、电导率、介电响应 | 固定参数化路线、力场/电荷策略、建模与分析规范，按性质收敛标准调整采样；不同配比/浓度/温度是不同任务，不能复用为同一物性 |

DFT 的溶剂—溶剂包括同种和实际共同出现的异种组分对；“溶质”不含混使用，Li⁺、阴离子、盐离子对和 Li₂Sₓ 的身份分别明确。多硫化物种类及是否加入 MD 体系必须统一标注；加入固定多硫化物的模拟是标准化探针体系，不冒充运行电池某一 SOC 的完整组成。反应、解离、质子转移造成对象改变时标记复核，不能把反应产物能量混入非反应结合能。

**能量定义建议。** 若采用 E_bind = E_AB(opt) − E_A(opt) − E_B(opt)，片段为各自优化结构，负值表示相对分离组分稳定；复合物构型下冻结片段计算的 E_int 另存，两者不混。先统一一种环境作为比较描述符；气相结合能不标成真实电解液溶剂化自由能。选用含色散的方案、检查基组重叠误差与阴离子弥散基组需求；具体计算级别先在代表体系上验证再冻结。

**软件建议，未选定。** 当前分子/小团簇任务优先 Gaussian（若有许可证和组内经验），无对应条件时评估 ORCA；VASP 留给明确的周期体系/电极界面需求，不因其能算而作为所有分子对的默认引擎。MD 暂以 LAMMPS 路线评估，可复用 MISPR 的 Gaussian—LAMMPS 管理思路；已有成熟 GROMACS 流程时可比较后择一。不同时建立多套不可比的主生产协议。

```text
文献组分/配方清单 → 身份核对与去重 → 选择固定协议 → 生成任务清单/资源估计
                           ↓
DFT：多构型生成/预筛 → 优化与能量计算 → 收敛/构型/对象检查 → 相互作用特征
MD ：配方建模/参数化 → 平衡 → 生产采样 → 结构/输运分析与收敛检查 → 配方特征
                           ↓
解析与单位核对 → 可追溯数据库 → 原文配方关联 → 分析集
                           ↑
失败分类 → 有限次同协议重试；需改变科学协议的任务转待复核，不静默改方法
```

**agent 分工。** LLM 协助任务解释、异常分类与报告；数值来自量化/MD 引擎，模板、调度、解析和入库由确定性程序执行。agent 不自由为每个体系更换泛函/力场以求成功，不把失败或未收敛任务标成可用；可预设重启/续算等不改变物理方法的恢复策略，记录每次尝试并限制重试次数。任务状态至少包含待执行、运行中、成功待质检、通过、失败、待人工复核；支持断点恢复和已完成结果缓存。

**缓存与追溯。** 键包含规范结构/组分、配比与浓度基准、温度、多硫化物状态、计算协议版本；MD 另记规模/随机种子/重复任务，DFT 另记电荷自旋和构型。保存输入、软件版本、参数文件、日志、必要轨迹/结构、原始结果、派生脚本版本及质检状态。参数文件哈希参与追溯；软件升级或协议变更不覆盖旧结果。

**验证与预算。** 建议先用少量有参考数据、覆盖醚/含氟醚及不同盐环境的体系验证；具体数量和预算待资源核实。DFT 检查多构型搜索与代表体系更高一级计算的相对排序；MD 用独立重复或分块采样检查密度/结构及动力学收敛，电导率区分 Nernst–Einstein 估计与包含离子关联的方法，黏度/介电响应单列收敛要求。统一的是可复现协议与质量准则，不是所有体系强行同一运行时长。

先扩展成本较低的组分对特征，再扩展配方级 MD；常规固定拓扑 MD 不承担 SEI 成膜反应解释。不预先承诺全库所有配方、所有物性都能成功补齐；失败和结构/力场不支持的体系登记覆盖率。

**参考资源（2026-10-29 查阅）。** [ComBat](https://github.com/rashatwi/combat) 提供锂硫相关结构、计算结果及模拟文件，具体字段有不同配方/多硫化物条件，适合作为基准而非无条件拼接；[OEDB](https://oedb.jp/about) 提供电解液数据库及 MCP 接口；[MISPR](https://github.com/molmd/mispr) 提供 Gaussian/LAMMPS 自动工作流、调度、解析和数据库管理思路；[VASP 静电修正文档](https://vasp.at/wiki/index.php/Electrostatic_corrections) 说明带电/偶极分子周期计算的额外收敛问题。

#### 7.17a 计算执行方案 v1（2026-11-05 用户定；尚未开算）

**用途（用户定）。** DFT/MD 直接计算，不用机器学习去预测 DFT/MD 的量；结果作为后续表述（文字）矛盾分析的输入特征，不再用于性能预测。表述里先用高/低分档找规律，找原因时回到具体数值（带误差）。只保留有文献证明能算准、并能用实测核对的特征。

**9 个特征。** 盒子里不放多硫化物，原因有两个：多硫化物相关特征已删；论文实测的电导率、黏度、拉曼用的都是新鲜电解液，这样才能核对。

| # | 特征 | 计算方法 | 文献依据 | 核对用的实测 |
|---|---|---|---|---|
| ① | Li⁺ 溶剂化自由能（按溶剂算一次，各篇共用） | DFT 团簇—连续介质法（准化学理论）。按 Itkis 推荐的“单体循环”计算：Li⁺ + n 个溶剂分子 → [Li(S)ₙ]⁺，放在 SMD 隐式溶剂中。构型先用 CREST/GFN2-xTB 预筛，取能量最低的几个做 DFT 优化和频率计算。n、热力学循环与计算级别的细节，开算前从 Itkis 补充材料核实 | [Itkis 等 PCCP 2021](https://pubs.rsc.org/en/content/articlehtml/2021/cp/d1cp01454d)：10 种溶剂（含 DME、DMSO、DMF、环丁砜、乙腈、DMA），单体循环最接近由实验推算的值；另一种循环平均差约 14 kcal/mol。[Sandia（PC）](https://www.osti.gov/servlets/purl/1184745)：Li⁺ 转移自由能与实验一致。[Kwabi 等](https://www.rsc.org/suppdata/c5/cp/c5cp02937f/c5cp02937f1.pdf)：Li⁺ 溶剂化能与 DN 走势一致 | 手册 DN 中测得可靠的常见溶剂（DMF、DMSO 经 [Katayama 2012](https://link.springer.com/article/10.2116/analsci.28.103) 重测一致），比排序；Itkis 参考值 |
| ② | Li⁺–阴离子结合能（按配方） | MD，定义照 Kim 2021（开算前从其补充材料确认） | [Kim 等 JACS 2021](https://web.stanford.edu/group/cui_group/papers/Kim_Cui_JACS_2021.pdf)：6 种阴离子的 MD 结合能与电位法实测溶剂化能趋势一致 | 阴离子排序；拉曼阴离子谱带 |
| ③ | Li⁺ 溶剂配位数 | MD。按 CN = 4πρ∫₀^rmin g(r)r²dr 积分到第一极小；另记第一层不同溶剂分子数 | ComBat；Kim 2021（随浓度变化的趋势与实测一致）；[Adv. Sci. 2025](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC12462972/)（166 个盐—溶剂体系） | 同配方拉曼/NMR 溶剂化数据 |
| ④ | Li⁺ 阴离子配位数 | 同 ③ | 同 ③ | 同 ③ |
| ⑤ | 离子聚集比例（SSIP/CIP/AGG） | MD 团簇统计（MDPropTools） | ComBat；Adv. Sci. 2025 | 拉曼阴离子谱带拆分 |
| ⑥ | 游离溶剂比例 | MD：与任何 Li⁺ 都不在 r_min 内的溶剂分子占比 | 与 ⑤ 同一团簇统计；**专门对照 MD 与拉曼的文献尚未找到，依据较弱** | 拉曼游离/配位溶剂谱带 |
| ⑦ | 离子电导率 | MD 电荷电流相关函数（Green–Kubo，含离子关联）；Nernst–Einstein 估计另存，不混用 | ComBat；[Park 等 2018](https://arxiv.org/pdf/1710.09221)：DME/DOL + LiTFSI/LiNO₃，总电导率和 Li⁺ 迁移数与实验吻合较好 | 文献实测电导率 |
| ⑧ | Li⁺ 迁移数 | MD；计算定义须对应实测方法（Bruce–Vincent 与自扩散比不同），只比排序 | Park 2018 | 文献实测迁移数 |
| ⑨ | 黏度 | MD 压力张量相关函数（Green–Kubo），多条独立短轨迹；最费机时，放最后 | ComBat（每体系 10–80 条，各 1–5 ns）；Park 2018 提示动力学偏慢 | 文献实测黏度；核对不过就删 |

- **顺带保存、不作特征**：各组分自扩散系数、密度（平衡后先和实测密度比，用于早期质检）、RDF。
- **已删**：
  - 溶剂–多硫化物结合能、Li⁺–多硫化物端位 S 配位数：没有找到和实验对比过的文献；ComBat 的 BE_PS 排序还有反常。
  - 所有气相结合能：只作方法核对。
  - 介电响应：电解液导电，简单的偶极涨落公式不适用。
  - 偶极矩、原子电荷：只作副产物。
- **DN 不作特征。**
  - DN 可以计算：DFT 算溶剂–SbCl₅ 加合焓，加隐式二氯乙烷，再线性校准到实验 DN。
  - 但它与 ① 高度重复，而且 [Gal 等 2019](https://peeref.com/works/18945127) 指出 SbCl₅ 体系对部分化合物与实验不符。
  - 手册 DN 只用来核对 ①。
- **多硫化物一侧没有能算准的量**，只能由 ①（DN 那条机理）和 ⑥ 间接覆盖。

**统一 MD 设置。** 沿用 ComBat 补充材料的做法，改动另注：

- 力场与电荷：
  - 溶剂用 OPLS-2005。ComBat 已公开 56 种溶剂的参数，可直接复用；其余溶剂用 Maestro 免费版的 ffld_server 生成。
  - TFSI⁻/FSI⁻ 用 Lopes–Pádua 一系参数，Li⁺ 用 Dang 参数。NO₃⁻ 参考 Park 2018，待核实。
  - 离子电荷按 1/√ε∞ 缩放（ECC）。
- 建盒与相互作用：Packmol 建盒；LJ 截断 1.2 nm；静电用 PPPM。
- 流程：
  1. 最小化；
  2. 298.15 K、1 atm 下 NPT 2 ns；
  3. 500 K 熔融 2 ns，再分 4 步降回 298.15 K，共 3 ns；
  4. NVT 正式模拟 5 ns，步长 1 fs。
- **本课题的改动**：正式模拟独立重复 3 次，同时用于误差范围和黏度；同时输出坐标、速度、压力张量，一次分析得到 ②–⑨。
- 对照参考：ComBat 原用 LAMMPS 3Mar2020 + MISPR 0.0.2 + Gaussian 16 C.01（补充材料）。

**软件。**

- **DFT**：教学服务器 Gaussian 16 A.03（DME 频率小样已通过）。ORCA 6.0.1（M6，学术免费）作备选，也用来算 DLPNO-CCSD(T) 参照。另用 CREST/xtb 预筛构型。
- **MD**：M6 上的 LAMMPS 29Sep2021 稳定版，须先用 `lmp -h` 确认含 MOLECULE、KSPACE、EXTRA-MOLECULE。缺包时自编译最新稳定版（22Jul2025 或 2026 稳定版）。配套 MISPR（锁定提交 efc14e1）、MDPropTools、Packmol。
- 版本定下后写进协议，全程不换。

**核对（“先校秤”）。** 文献只证明算法在它们的体系和力场下算得准；我们的配方有 TTE、LiFSI、LiNO₃、高浓度等文献没覆盖的情况，所以批量算之前要先核对。

- 用 243 篇试跑的 394 个建模配方里有实测值的配方：电导率 119、黏度 58、迁移数 47、溶剂化 50。
- 先算 20–30 个，再加约 8 种 DN 可靠的溶剂。
- 比排序和误差，达标的特征才批量算；不达标就换力场或删除。
- 达标线由用户在开算前定。

**并入 `simulation_agent/`（同一个 agent）。** 流程：

1. 读配方组成，标准化组成并去重（243 篇试跑可完全换算的配方去重后 1002 个）；
2. 分两类任务：DFT 按溶剂（①），MD 按配方（②–⑨）；
3. 提交、轮询、质检；
4. 写入特征表（数值 ± 误差、软件与协议版本）；
5. 挂回表述。

分三批推进：

- 第 0 批：校准；
- 第 1 批：矛盾配对涉及的配方，改动前后都算，先做 TTE、LiNO₃ 两组；
- 第 2 批：按需扩大。

**省钱做法：**

- 同一组成只算一次；
- 一套轨迹出 8 个特征，不为电导率/黏度另开盒子；
- DFT 先用 xtb 预筛构型；
- NPT 后先比密度，偏差大就不跑正式模拟；
- 黏度放最后，且只在需要时算；
- 多个小 DFT 任务打包占满整节点（教学服务器上次申请 2 核却按 64 核整节点分配）；
- 失败只按原方法有限重试；结果按软件与协议版本缓存。

**agent 现有功能：** 任务合同与哈希去重、SQLite 状态、重试与缓存、预算、Gaussian/ORCA 输入、日志初检、Slurm 脚本导出、MISPR 输入适配。

**还缺：** 构型搜索、力场生成、LAMMPS/MISPR 的 MD 接入、MDPropTools 分析、SSH 提交与轮询、与实测的自动对比。费用等第 0 批测出单配方 MD 和单溶剂 DFT 的实际核时后再估。

**开算前待办：**

2. 读 Kim 2021 补充材料，确认 ② 的定义；

5. 用户定达标线；
6. 第 0 批小样测核时。
